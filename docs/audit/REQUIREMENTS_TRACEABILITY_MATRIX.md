**Status Taxonomy:**
- **Verified Working:** Code exists, behavior inspected, passing test or runtime observation.
- **Implemented but Unverified:** Code exists, but effective end-to-end behavior is unproven or requires external service.
- **Partially Implemented:** Functional in part, but with significant architectural limitations.
- **Defective:** Clear implementation defect or reproducible design failure.
- **Missing:** Not implemented or no source code exists.
- **Blocked / Unknown:** Blocked by unavailable external dependencies, missing hardware, or external auth.

## 3. Top Architectural Priorities

1. **Defect REQ-002 (Task Planning Regex Hijacking):** Regex intent matching takes precedence over LLM reasoning and captures generative instructions as literal text (e.g. typing `"a thank-you letter to Bob"`).
2. **Defect REQ-003 (Lack of Native Model Function Calling):** Models are prompted to output JSON strings parsed with regex rather than utilizing native Gemini/OpenAI tool call APIs.
3. **Missing REQ-013 (Screenshot-to-Vision Grounding):** Screenshots are captured to disk but cannot be seen or reasoned about by any vision model.
4. **Missing REQ-015 (Persistent Browser Contexts):** Playwright uses ephemeral contexts, causing logins to be lost on close.
